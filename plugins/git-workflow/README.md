# git-workflow

Part of [skill-hive](https://github.com/hashgesh/skill-hive): agent skills for Claude Code and OpenCode.

Agent skills for the everyday git loop: create a well-named branch, write conventional commits with a gitmoji prefix, open a pull request with a generated summary, review pull requests, and cut a release with a CHANGELOG generated by git-cliff.

## Install

```
/plugin install git-workflow --marketplace hashgesh/skill-hive
```

or `/plugin marketplace add hashgesh/skill-hive` and then `/plugin install git-workflow@skill-hive`. Skills are namespaced, e.g. `/git-workflow:branch`, and Claude also picks them automatically from their descriptions.

## Skills

| Skill | Description | Requires |
|-------|-------------|----------|
| [branch](skills/branch/) | Create a well-named branch from the right base | `git`, `gh` (optional) |
| [changelog](skills/changelog/) | Generate changelog with git-cliff | `git-cliff` |
| [conventional-commit](skills/conventional-commit/) | Conventional commits with gitmoji | `git` |
| [pull-request](skills/pull-request/) | Auto-generate PR summary | `gh` or `glab` (optional) |
| [release](skills/release/) | Create release with changelog and tag | `git-cliff`, `gh` (optional) |
| [review](skills/review/) | Auto-review PRs with analysis | `gh` |

The CLIs are not bundled; each skill checks for its tools and shows the install command when one is missing.

## What it runs

The skills run `git` locally, `git-cliff` to render the changelog, and `gh` or `glab` when you ask them to read or open pull requests, post a review or publish a release. Anything that pushes, comments or publishes is shown to you and confirmed first.
